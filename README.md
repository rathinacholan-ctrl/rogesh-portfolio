# Rogesh N Portfolio

A responsive red + yellow personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `rogesh-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live Pages URL. It normally follows:
   `https://YOUR-GITHUB-USERNAME.github.io/rogesh-portfolio/`

GitHub Pages hosts static HTML/CSS/JavaScript sites directly from a repository.
